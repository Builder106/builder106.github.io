# Portfolio Roadmap

Builder106 portfolio site development and feature roadmap.

## v1.1: Showcase & Performance Polish (done)

- **Project Matrix Redesign**: Interactive, categorized project explorer across SWE, Quant, Cyber, and AI/ML.
- **A11y & Performance Baseline**: CI blocks on axe (WCAG 2.2 A/AA), Lighthouse accessibility 0.95, best practices 0.9, SEO 0.9 and layout shift under 0.1. Performance is tracked as a warning, since the CI runner draws the 3D scene without a GPU.

## v1.2: Interactive 3D & Demos

- **Interactive WebGL / Three.js Hero**: Tasteful, hardware-accelerated interactive elements.
- **Embedded Case Studies**: Detailed technical retrospectives and interactive architecture diagrams.
